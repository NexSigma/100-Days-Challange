## 🛠️ How to Add a New Day (Daily GitHub Stats Update)

To maintain your daily streak and update your GitHub stats:

1. Open your terminal in this repository.
2. Run the helper script to auto-scaffold today's folder:
   ```bash
   node scripts/create-day.js day-06-graph-algorithms
   ```
3. Implement your code in `solution.js`, write tests in `solution.test.js`, and add key learnings to `notes.md`.
4. Run tests:
   ```bash
   npm test
   ```
5. Commit & Push to GitHub:
   ```bash
   git add .
   git commit -m "feat(day-06): Add Graph BFS/DFS implementations & test suite"
   git push origin main
   ```
